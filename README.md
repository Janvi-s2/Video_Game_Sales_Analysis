# Video_Game_Sales_Analysis

## Description

This repository contains an Exploratory Data Analysis (EDA) of video game sales data. The project uses Python to analyze video game sales trends and uncover insights related to gaming platforms, genres, publishers, release years, and sales performance across different regions.

The dataset contains information about video games, including their names, platforms, release years, genres, publishers, and sales figures across different geographical regions. The data is analyzed using Python libraries to identify patterns, compare sales performance, and generate meaningful business insights.

## Dataset Features

Here's a brief overview of the dataset's features:

- **Name**: Name of the video game.
- **Platform**: Gaming platform on which the game was released.
- **Year**: Year in which the game was released.
- **Genre**: Category or type of the video game, such as Action, Sports, Racing, and Role-Playing.
- **Publisher**: Company responsible for publishing the video game.
- **NA_Sales**: Sales generated in North America.
- **EU_Sales**: Sales generated in Europe.
- **JP_Sales**: Sales generated in Japan.
- **Other_Sales**: Sales generated in other regions.
- **Global_Sales**: Total worldwide sales of the video game.

## Analysis Findings

The project explores different aspects of video game sales data. Key analysis areas include:

1. **Genre Analysis**: Identifying popular video game genres based on their sales performance.
2. **Platform Analysis**: Comparing sales across different gaming platforms.
3. **Publisher Analysis**: Identifying publishers with the highest number of games and sales performance.
4. **Regional Sales Analysis**: Comparing video game sales across North America, Europe, Japan, and other regions.
5. **Year-wise Sales Analysis**: Exploring changes in video game sales over different years.
6. **Global Sales Analysis**: Identifying top-selling video games and analyzing overall worldwide sales.
7. **Comparative Analysis**: Understanding relationships between genres, platforms, publishers, and sales figures.

## Conclusion

This project provides a detailed analysis of video game sales data and helps understand gaming industry trends, popular genres, platform performance, and regional sales patterns. The visualizations and findings offer useful business insights that can help identify successful gaming categories, understand market trends, and support better business decisions.

The project also demonstrates practical skills in data cleaning, data analysis, grouping, statistical exploration, and data visualization using Python.
